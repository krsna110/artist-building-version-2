# Skill Outcomes card swipe animation

Only the existing Skill Outcomes / What You'll Learn cards have been enhanced. The original website copy, images, colors, typography, section order, and desktop card grid are preserved.

On mobile (560px and below), the existing cards form a layered deck. Visitors can swipe or drag left/right, use keyboard arrow keys, and the top card cycles automatically while the deck is visible. Reduced-motion preferences disable autoplay.

Files added: `skill-card-swipe.css` and `skill-card-swipe.js`. They are linked from `index.html`; all original files and assets remain in place.
